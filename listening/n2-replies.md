## 例の件
男: 例の件、部長に話しておいてくれた？ = Did you tell the manager about that matter?
- あ、すみません、うっかりしてました。すぐ話します。 * = Oh, sorry, it slipped my mind. I'll tell him right away.
- はい、部長から話してもらいました。 = Yes, the manager told me.
- ええ、例の件は話しにくいですね。 = Yes, that matter is hard to talk about.
> 話しておいてくれた？ asks whether it was done; admitting you forgot fits.

## 会議
女: 今日の会議、思ったより長引いちゃったね。 = Today's meeting dragged on longer than expected.
- 本当、もうくたくただよ。 * = Really, I'm worn out.
- うん、もっと長くしようか。 = Yeah, shall we make it longer?
- え、まだ始まってないの？ = What, it hasn't started yet?
> 長引いた: it ran long. くたくた: exhausted.

## お時間
男: お忙しいところ申し訳ないのですが、少しお時間いただけますか。 = Sorry to bother you when you're busy, but could I have a moment?
- ええ、構いませんよ。 * = Sure, that's fine.
- はい、お時間を差し上げます。 = Yes, I will present you with time.
- いいえ、忙しくないところです。 = No, it's a place that isn't busy.
> A polite request for a moment; 構いませんよ grants it.

## 気が利く
女: 山田さんって、本当に気が利くよね。 = Yamada is really thoughtful, isn't she?
- うん、いつも先回りして動いてくれるよね。 * = Yeah, she always does things before you even ask.
- うん、ちょっと気が短いよね。 = Yeah, she's a bit short-tempered.
- え、山田さん、具合悪いの？ = What, is Yamada unwell?
> 気が利く: attentive, thoughtful. 気が短い is short-tempered, a different expression.

## 企画
男: この企画、いっそのこと一から考え直したらどうかな。 = What if we just rethought this project from scratch?
- そうですね、そのほうが早いかもしれません。 * = True, that might be quicker.
- はい、一つだけ考えました。 = Yes, I thought of just one.
- いいえ、いっそのこと終わりました。 = No, it ended altogether.
> いっそのこと: rather than patching it, go all the way and start over.

## 引っ越しの準備
女: 引っ越しの準備、はかどってる？ = Is your moving prep going well?
- それが、なかなか進まなくて。 * = Actually, it's barely moving.
- うん、手伝ってくれてありがとう。 = Yeah, thanks for helping.
- ええ、はかどってください。 = Yes, please make progress.
> はかどる: to make good progress. それが… introduces a "not really" answer.

## 耳に入れる
女: この件、課長の耳に入れておいたほうがいいんじゃない？ = Shouldn't you let the section chief know about this?
- そうですね、早めに報告しておきます。 * = You're right, I'll report it soon.
- はい、耳が痛いです。 = Yes, that hurts to hear.
- ええ、課長は耳がいいですから。 = Yes, the chief has good ears.
> 耳に入れる: to let someone know.

## 見送る
男: せっかくのお誘いですが、今回は見送らせていただきます。 = Thank you for the kind invitation, but I'll have to pass this time.
- そうですか、残念です。またの機会に。 * = I see, that's a pity. Another time, then.
- では、駅まで見送りますね。 = Then I'll see you off at the station.
- ええ、ぜひいらしてください。 = Yes, please do come.
> 見送る here means to pass on something, not to see someone off.

## 口ばかり
女: 田中さんって、いつも口ばかりで、なかなか動かないよね。 = Tanaka is all talk and never actually does anything.
- 確かに、言うだけならだれでもできるよね。 * = True, anyone can just talk.
- うん、本当によく食べるよね。 = Yeah, he really eats a lot.
- 口が上手で、いいよね。 = He's a smooth talker, that's nice.
> 口ばかり: all talk, no action.

## 不備
男: 申し訳ありません、お送りした資料に不備がございました。 = I'm very sorry; there was an error in the documents we sent.
- 分かりました。修正したものを送っていただけますか。 * = Understood. Could you send the corrected version?
- はい、不備をありがとうございます。 = Yes, thank you for the error.
- いいえ、資料は備えておきました。 = No, I prepared the documents.
> 不備: a deficiency or mistake; ask for the fix.

## 白紙
女: 結局、あの企画は白紙に戻ったらしいよ。 = Apparently that project went back to square one in the end.
- えっ、あんなに準備したのに。 * = What, after all that preparation?
- じゃあ、白い紙を用意しよう。 = Then let's get some white paper.
- よかった、無事に決まったんだね。 = Great, so it was decided safely.
> 白紙に戻る: to be cancelled and start from nothing.

## ごちそう
男: 今日は私がごちそうしますよ。 = Today's on me.
- いえいえ、それは申し訳ないです。 * = Oh no, I couldn't let you.
- ごちそうさまでした。また作ってください。 = Thanks for the meal. Please cook again.
- はい、ごちそうしてあげます。 = Yes, I'll treat you.
> ごちそうする: to treat someone. Politely protesting is the usual first reply.

## めどが立つ
女: 例のプロジェクト、ようやくめどが立ったよ。 = That project finally looks like it'll work out.
- それはよかった。長かったね。 * = That's great. It took a long time.
- えっ、まだ見通しが立たないの？ = What, still no prospects?
- じゃあ、早く始めないとね。 = Then we'd better start soon.
> めどが立つ: the end is in sight.

## 気を遣う
男: そんなに気を遣わなくてもいいのに。 = You really didn't need to go to such trouble.
- いえ、ほんの気持ちですから。 * = Oh, it's just a small token.
- はい、気をつけます。 = Yes, I'll be careful.
- じゃあ、もっと遣いましょうか。 = Then shall I use more?
> Said on receiving a gift; ほんの気持ち: just a small token.

## 幹事
女: 今度の飲み会、幹事を引き受けてもらえないかな。 = Could you take on organising the next drinks party?
- 私でよければ、やりますよ。 * = If I'll do, I'll do it.
- ありがとう、幹事をしてくれて。 = Thanks for organising it.
- じゃあ、だれかに頼んでもらえますか。 = Then could you ask someone?
> 引き受ける: to take on. 私でよければ accepts modestly.
