---
title: 〜そう (looks like)
meaning: looks … / seems about to …
level: N4
order: 60
detect: そう[接尾]
see: sou-hearsay, you-da-mitai
---

**stem + そう** = "looks …", from what you can see.

| | |
|---|---|
| い-adjective: drop い | 美味しい → 美味し**そう** |
| な-adjective | 元気 → 元気**そう** |
| verb ます-stem | 降る → 降り**そう** (looks like it's going to rain) |
| irregular | いい → **よさそう**, ない → **なさそう** |

It acts like a な-adjective: 美味しそう**な**ケーキ, 元気そう**に**見える.

> 〜そう here is about what you **see**. For "I heard that…", see the hearsay そうだ.

## Examples
- このケーキ、美味しそう！ = This cake looks delicious!
- 雨が降りそうですね。 = It looks like it's going to rain.
- 楽しそうな人たちだ。 = They look like fun people.

## Quiz
- 高い → looks expensive = 高そう | 高いそう | 高くそう
- いい → looks good = よさそう | いいそう | よそう
