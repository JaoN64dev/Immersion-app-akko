---
title: 〜てある
meaning: has been done (and stays that way)
level: N4
order: 35
detect: て|で + ある
see: te-iru, te-oku
---

**て-form + ある** describes a state that **someone made on purpose**. The thing takes **が**.

| | |
|---|---|
| 窓が開い**ている** | The window is open (just a fact). |
| 窓が開け**てある** | The window has been opened (someone opened it on purpose). |

It's used with verbs that take an object (開ける, 書く, 置く, 貼る…).

## Examples
- 黒板に名前が書いてある。 = A name is written on the blackboard.
- ビールは冷蔵庫に冷やしてあります。 = The beer has been chilled in the fridge.
- 机の上に花が飾ってある。 = Flowers have been put on the desk.

## Quiz
- 壁にポスターが貼っ＿＿＿。 = てある | ている | てみる
