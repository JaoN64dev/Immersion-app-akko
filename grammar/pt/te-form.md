---
title: Forma て
meaning: a forma de ligação por trás de ている, てください, てもいい e mais
---

A **forma て** liga ações ("e depois") e forma muitas estruturas. Como fazer a partir da forma de dicionário:

| terminação | forma て | exemplo |
|---|---|---|
| る (ichidan) | て | 食べる → 食べ**て** |
| う, つ, る | って | 買う → 買**って**, 待つ → 待**って**, 帰る → 帰**って** |
| む, ぶ, ぬ | んで | 読む → 読**んで**, 遊ぶ → 遊**んで** |
| く | いて | 書く → 書**いて** |
| ぐ | いで | 泳ぐ → 泳**いで** |
| す | して | 話す → 話**して** |
| irregulares | | する → して, 来る → 来て, 行く → 行**って** |

O passado (forma た) funciona do mesmo jeito: é só trocar て→た e で→だ: 読んだ, 書いた.

## Examples
- 朝起きて、シャワーを浴びて、学校に行きます。 = Eu acordo, tomo banho e vou para a escola.
- 本を読んで寝ました。 = Li um livro e fui dormir.
- 手紙を書いて、出しました。 = Escrevi uma carta e mandei.

## Quiz
- 飲む → forma て? = 飲んで | 飲みて | 飲って
- 行く → forma て? = 行って | 行いて | 行きて
- 話す → forma て? = 話して | 話って | 話いて
- 待つ → forma て? = 待って
