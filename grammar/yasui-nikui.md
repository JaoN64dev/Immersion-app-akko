**ます-stem + やすい** = easy to do. **ます-stem + にくい** = hard to do. Both conjugate like い-adjectives.

- このペンは書き**やすい**。This pen is easy to write with.
- 彼の字は読み**にくい**。His handwriting is hard to read.

〜づらい also means "hard to", usually because it's uncomfortable: 言い**づらい** (hard to say).

## Examples
- この本は分かりやすいです。 = This book is easy to understand.
- 冬は風邪をひきやすい。 = You catch colds easily in winter.
- この靴は歩きにくい。 = These shoes are hard to walk in.

## Quiz
- この説明は分かり＿＿＿。(easy) = やすい | にくい | すぎる
- 使う → hard to use = 使いにくい | 使うにくい | 使ってにくい
