The **ば-form** states a condition: "if X, then Y".

| | ば-form |
|---|---|
| う-verbs (u → e + ば) | 行く → 行**けば**, 飲む → 飲**めば** |
| る-verbs | 食べる → 食べ**れば** |
| irregular | する → **すれば**, 来る → **来れば** (くれば) |
| い-adjectives | 高い → 高**ければ**, いい → **よければ** |
| negative | 行かない → 行か**なければ** |

Useful set phrases: 〜ばいい (all you need to do is…), 〜ばよかった (I wish I had…).

## Examples
- 急げば間に合う。 = If you hurry, you'll make it.
- どうすればいいですか。 = What should I do?
- もっと早く来ればよかった。 = I should have come earlier.

## Quiz
- 書く → ば-form? = 書けば | 書きば | 書くば
- 安＿＿＿買います。 = ければ | いれば | くば
