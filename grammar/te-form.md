meaning: the joining form behind ている, てください, てもいい and more

The **て-form** joins actions ("and then") and builds many patterns. How to make it from the dictionary form:

| ending | て-form | example |
|---|---|---|
| る (ichidan) | て | 食べる → 食べ**て** |
| う, つ, る | って | 買う → 買**って**, 待つ → 待**って**, 帰る → 帰**って** |
| む, ぶ, ぬ | んで | 読む → 読**んで**, 遊ぶ → 遊**んで** |
| く | いて | 書く → 書**いて** |
| ぐ | いで | 泳ぐ → 泳**いで** |
| す | して | 話す → 話**して** |
| irregular | | する → して, 来る → 来て, 行く → 行**って** |

The past (た-form) works the same way: just change て→た and で→だ: 読んだ, 書いた.

## Examples
- 朝起きて、シャワーを浴びて、学校に行きます。 = I get up, take a shower and go to school.
- 本を読んで寝ました。 = I read a book and went to sleep.
- 手紙を書いて、出しました。 = I wrote a letter and sent it.

## Quiz
