**stem + すぎる** = "too much". It's a る-verb.

| | |
|---|---|
| verb ます-stem | 食べ**すぎる** (eat too much) |
| い-adjective: drop い | 高**すぎる** (too expensive) |
| な-adjective | 静か**すぎる** (too quiet) |
| irregular | いい → **よすぎる**, ない → **なさすぎる** |

As a noun: 飲み**すぎ** (drinking too much).

## Examples
- 昨日、飲みすぎた。 = I drank too much yesterday.
- この問題は難しすぎる。 = This question is too hard.
- 働きすぎは体に悪い。 = Overworking is bad for your health.

## Quiz
- このカレーは辛＿＿＿。 = すぎる | いすぎる | くすぎる
- 食べる → ate too much = 食べすぎた | 食べるすぎた | 食べてすぎた
