---
title: 〜たい
meaning: querer …
---

**Raíz de ます + たい** = "querer hacer". Se conjuga como un adjetivo い.

| | |
|---|---|
| quiero | 食べ**たい** |
| no quiero | 食べ**たくない** |
| quería | 食べ**たかった** |
| educado | 食べ**たいです** |

Lo que quieres puede llevar **が** o **を**: 水**が**飲みたい / 水**を**飲みたい.

> たい es para **tus propios** deseos. Para otras personas, usa 〜たがっている: 弟は行きたがっている.

## Examples
- 日本に行きたいです。 = Quiero ir a Japón.
- 今日は何もしたくない。 = Hoy no quiero hacer nada.
- あの映画、ずっと見たかった！ = ¡Hace mucho que quería ver esa película!

## Quiz
- 寿司が食べ＿＿＿です。 = たい | たく | たり
- 行く → no quise ir = 行きたくなかった | 行きたいなかった | 行くたくなかった
