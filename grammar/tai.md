**ます-stem + たい** = "want to do". It conjugates like an い-adjective.

| | |
|---|---|
| want to | 食べ**たい** |
| don't want to | 食べ**たくない** |
| wanted to | 食べ**たかった** |
| polite | 食べ**たいです** |

The thing you want can take **が** or **を**: 水**が**飲みたい / 水**を**飲みたい.

> たい is for **your own** wishes. For other people, use 〜たがっている: 弟は行きたがっている.

## Examples
- 日本に行きたいです。 = I want to go to Japan.
- 今日は何もしたくない。 = I don't want to do anything today.
- あの映画、ずっと見たかった！ = I've wanted to see that film for ages!

## Quiz
- 寿司が食べ＿＿＿です。 = たい | たく | たり
- 行く → didn't want to go = 行きたくなかった | 行きたいなかった | 行くたくなかった
