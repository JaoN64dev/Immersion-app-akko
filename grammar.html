Add your own lessons

Lessons are Markdown files in the grammar folder of the app. To add one, copy grammar/_template.md, rename it and edit it. Changes show up when you reload this page, without restarting the server.

Each file sets its title, meaning, level and order at the top. Its detect: lines describe how to find the grammar in subtitles and texts. grammar/README.md explains every option.
