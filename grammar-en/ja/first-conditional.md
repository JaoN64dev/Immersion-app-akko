---
title: 仮定 (if + 現在形, will)
meaning: もし〜なら…する（実際に起こりうること）
---

**if + 現在形, will + 原形** は、実際に起こりうる未来の条件です（第一条件文）。

> **If** it **rains** tomorrow, I **will stay** home.（明日雨なら家にいる）

- if の中は **未来でも現在形**: × If it will rain → ○ If it **rains**
- いつも本当のこと（ゼロ条件文）: **If** you **heat** ice, it **melts**.
- **unless** = if ... not: I won't go **unless** you come.

> 下線は if のある文すべてにつきます。どの条件文かは、後ろの形（will / would / would have）で見分けましょう。

## Examples
- If you hurry, you'll catch the train. = 急げば電車に間に合うよ。
- If I have time, I will call you. = 時間があったら電話します。
- We'll go to the beach if it's sunny. = 晴れたら海に行きます。
