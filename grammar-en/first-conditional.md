**if + present, will + verb** is for real possibilities in the future (the *first conditional*).

> **If** it **rains** tomorrow, I **will stay** home.

- Inside the if part, use the **present**, even about the future: ~~If it will rain~~ → If it **rains**.
- Always true (*zero conditional*): **If** you **heat** ice, it **melts**.
- **unless** = if … not: I won't go **unless** you come.

> Every sentence with *if* gets this underline. Look at the rest of the sentence (will / would / would have) to see which kind it is.

## Examples
- If you hurry, you'll catch the train.
- If I have time, I will call you.
- We'll go to the beach if it's sunny.

## Quiz
- If it ___ tomorrow, we will cancel the game. = rains | will rain | rained
- If you study, you ___ pass. = will | would | are
