---
title: Condicionais com if (first conditional)
meaning: se isso acontecer, aquilo vai acontecer
---

**if + presente, will + verbo** é para possibilidades reais no futuro.

> **If** it **rains** tomorrow, I **will stay** home. (Se chover amanhã, vou ficar em casa.)

- Na parte do if usa-se o **presente**, mesmo falando do futuro: ~~If it will rain~~ → If it **rains**. (Em português usamos o futuro do subjuntivo, "se chover"; em inglês, o presente.)
- Sempre verdade (*zero conditional*): **If** you **heat** ice, it **melts**.
- **unless** = se ... não: I won't go **unless** you come.

> Toda frase com *if* ganha este sublinhado. Veja o resto da frase (will / would / would have) para saber qual condicional é.

## Examples
- If you hurry, you'll catch the train. = Se você se apressar, pega o trem.
- If I have time, I will call you. = Se eu tiver tempo, te ligo.
- We'll go to the beach if it's sunny. = Vamos à praia se fizer sol.
